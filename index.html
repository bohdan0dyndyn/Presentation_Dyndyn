Програмний продукт

«Alumni Database»

03 · Алгоритм

Модуль Data Engineer

1

Визначення типу файлу

Тип визначається за сигнатурою байтів, а не розширенням.

if (buffer[0] === 0x50) {
  // .xlsx — ZIP-архів
  parseExcel(buffer);
} else { parseCsv(buffer); }
2

Визначення кодування CSV

Спочатку читається як UTF-8. Якщо є символи-замінники — перекодується з Windows-1251.

// UTF-8 → перевірка → Win-1251
const text = hasGarbage(utf8)
  ? iconv.decode(buf, 'win1251')
  : utf8;
3

Функція findVal

Пошук колонок за масивом можливих ключових слів для підтримки різних версій ЄДЕБО.

function findVal(row, keys) {
  return keys.map(k => row[k])
    .find(v => v !== undefined);
}
4

Транзакції SQLite

ROLLBACK при будь-якій помилці — жодного часткового завантаження.

db.run('BEGIN TRANSACTION');
try { /* INSERT */ db.run('COMMIT'); }
catch(e) { db.run('ROLLBACK'); }

07 · Наукові результати

Результати досліджень

01

Алгоритм визначення типу файлу за сигнатурою байтів

Надійне визначення формату без покладання на розширення — перевірка першого байту буфера (0x50 для ZIP/XLSX).

02

Метод автоматичного визначення кодування кириличних CSV-файлів

Алгоритм детектування (UTF-8 vs Windows-1251) через перевірку символів-замінників у декодованому тексті.

03

Функція гнучкого пошуку полів у неоднорідних джерелах (findVal)

Пошук за масивом можливих ключів замість жорсткого маппінгу — корисний патерн для інтеграції з держ. системами.

04

Транзакції SQLite для атомарності пакетного імпорту

BEGIN TRANSACTION / ROLLBACK унеможливлює часткову міграцію даних при виникненні помилок.
